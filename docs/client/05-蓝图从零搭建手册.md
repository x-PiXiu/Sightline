# 蓝图从零搭建手册（基于 C++ 基类）

> **定位**：替代《04-蓝图迁移执行手册》——不再迁移旧蓝图，直接在 C++ 基类上从零搭建干净的客户端。
> **前提**：`ASightlineCharacter/RemotePawn/Weapon` 三个 C++ 基类已就绪并编译通过（当前客户端仓库 main 分支）。
> **资产策略**：
> - 第一人称（我看到的）：XL_FPSPack 的手臂+枪，不动；
> - 第三人称（别人看到的）：UE 5.7 引擎内置 Mannequin（裸身，无持枪动画）——M4 打磨时从 Lyra Migrate 持枪动画升级外观。
> **纪律**：蓝图里零判断零字节——所有逻辑在 C++，蓝图只接 `BP_On*` 表现钩子和配置资产。
> **预计耗时**：2~2.5 小时（无需下载任何资产）。

## 第 2 步：ABP_RemotePawn（远端玩家动画蓝图）—— 0~30 分钟

**目标**：根据傀儡速度自动切换 Idle/Walk/Run 动画。

### 2.1 方案 A：直接用引擎自带 ABP_Manny（推荐，零工作量）

第 1 步已把 Anim Class 指定为 `ABP_Manny`——它内部已有完整的 Idle/Walk/Run/Jump 状态机和 Transition 条件。**不需要创建任何新动画蓝图，直接跳到第 3 步。**

> **学习点**：ABP_Manny 的 Transition 条件用的是 `Get Velocity → Vector Length`——
> 这正好读的是 C++ `ASightlineRemotePawn::GetVelocity()` 的覆写。
> `SetActorLocation` 不写引擎速度，我们自己算并暴露——动画蓝图完全不知道网络的存在。

### 2.2 方案 B：自己搭建 ABP（学习价值更高，30 分钟）

如果想理解动画蓝图的工作方式，可以自建：

1. Content/Code/Player/Animation/ 右键 → Animation Blueprint → 选 Mannequin 骨架
2. 命名 `ABP_RemotePawn` → 打开 AnimGraph

#### 状态机

```
AnimGraph 右键 → Add State Machine → 打开它

内部三个状态：
┌─────────┐      Speed > 10       ┌─────────┐      Speed > 300      ┌─────────┐
│   Idle  │ ───────────────────►  │  Walk   │ ───────────────────►  │   Run   │
│         │ ◄───────────────────  │         │ ◄───────────────────  │         │
└─────────┘      Speed < 10       └─────────┘      Speed < 300      └─────────┘

每个状态内部：右键 → 搜引擎 Mannequin 的动画资产（AM_Idle/AM_Walk/AM_Run）→ 拖入 → 连到 Output Pose
```

#### 转换条件（每个 Transition Rule 里）

```
Try Get Pawn Owner → Get Velocity → Vector Length
    ↓
Greater Than (阈值: Idle→Walk=10, Walk→Run=300)
    ↓
连接到 Result（True = 转换，False = 留在当前状态）
```

#### 回 BP_RemotePawn 指定自建 ABP

Details → Mesh → Anim Class = `ABP_RemotePawn`（替换方案 A 的 ABP_Manny）。

## 第 3 步：BP_Player（本地第一人称角色）—— 30 分钟

**目标**：我的视角——手臂+枪+相机+输入映射，自动登录/上报/接收消息。

### 3.1 创建蓝图

1. Content/Code/Player/ 右键 → Blueprint Class → Parent = **SightlineCharacter**
2. 命名 `BP_Player`（或覆盖旧的 BP_FPSPlayer，如果已删除的话）→ 打开

### 3.2 Components（组件面板）

| 组件 | 设置 |
|---|---|
| **Mesh**（继承的主 Mesh） | 设为 **None** 或 **Hidden in Game**（不用它，用下面的 ArmsMesh） |
| **+ Add → Camera** | 命名 `FirstPersonCamera`；位置=(0, 0, 60)（眼睛高度）；`Use Pawn Control Rotation` = **true** |
| **+ Add → Skeletal Mesh** | 命名 `ArmsMesh`；父级 = `FirstPersonCamera`；Skeletal Mesh = XL_FPSPack 的手臂 Mesh；Anim Class = `ABP_Arms`（第 4 步创建）；**Visibility** → `Only Owner See` = true（只有我看到自己的手臂） |
| **+ Add → Capsule** | 无需动（继承自 Character 的碰撞体） |

### 3.3 Details 配置

| 分类 | 属性 | 值 |
|---|---|---|
| Sightline\|Config | Player Name | `UEPlayer`（或自定义） |
| Sightline\|Config | Auto Login | **true** |
| Sightline\|Config | Conn Config → Host | 服务器地址（如 `192.168.1.35`） |
| Sightline\|Config | Conn Config → Port | `8888` |
| Sightline\|Config | Remote Pawn Class | `BP_RemotePawn` |
| Sightline\|Config | Default Weapon Class | `BP_Weapon`（第 5 步创建） |
| Pawn | Use Controller Rotation Yaw | **false**（鼠标控制用 Add Controller Yaw Input） |
| Character Movement | Max Walk Speed | `600` |

### 3.4 Event Graph：输入绑定（蓝图唯一的逻辑——把输入连到引擎函数）

```
EnhancedActionEvent IA_Move → Get Action Value (Vector2D)
    ├── X → Add Movement Input (Right Vector × X)
    └── Y → Add Movement Input (Forward Vector × Y)

EnhancedActionEvent IA_Look → Get Action Value (Vector2D)
    ├── X → Add Controller Yaw Input (X)
    └── Y → Add Controller Pitch Input (Y)

EnhancedActionEvent IA_Fire (Started) → Get Current Weapon → Start Fire
EnhancedActionEvent IA_Reload (Started) → Get Current Weapon → Reload

Event BeginPlay → （不需要任何网络代码，C++ BeginPlay 全自动）
```

> **学习点**：迁移旧蓝图时要删一整片 BeginPlay 网络图；新建时根本没有——C++ `BeginPlay` 已经自动 Connect/Login/JoinRoom/BindEvent/SetTimer。你只管接输入和表现钩子。

### 3.5 表现钩子接线（Events 列表 → 右键 → Implement Event）

| 钩子 | 覆盖内容 |
|---|---|
| `BP_OnLoggedIn(NewPlayerId)` | Print String("PlayerId:" + ToString) |
| `BP_OnRttUpdated(RttMs)` | Print String("RTT:" + ToString) |
| `BP_OnHitReceived(Shooter,Damage,NewHp,bDead)` | Branch: bDead → Print("你被击杀") / 否则 Print("受到X伤害 HP:Y") |
| `BP_OnRespawned(Pos,NewHp)` | Print String("重生 HP:" + ToString) |
| `BP_OnKillConfirmed(Victim)` | Print String("击杀！") |
| `BP_OnGameOver(Winner,bIWon)` | Branch: bIWon → Print("你赢了") / 否则 Print("获胜者: " + Winner) |
| `BP_OnKicked(Reason)` | Print String("被踢 reason:" + Reason) |
| `BP_OnDisconnected()` | Print String("连接断开") |

> 后续 M4 打磨时把这些 Print 替换成 UMG Widget 效果（红闪/血条/击杀播报）。
> 现在先用 Print 验证数据流正确。

### 3.6 GameMode 配置

打开 `BP_FPSGameMode` → Details → Default Pawn Class = **BP_Player**。

### 3.7 本步验证

起服(`serve.sh 8888 debug`) → PIE → 屏幕显示 PlayerId + RTT 滚动 → 服务器日志 `msgid=1/3/5/10` 全出现。

## 第 4 步：ABP_Arms（手臂动画蓝图）—— 30 分钟

**目标**：第一人称手臂根据武器状态切换动画。

### 4.1 创建

Content/Code/Player/Animation/ 右键 → Animation Blueprint → 选 XL_FPSPack 的手臂骨架 → 命名 `ABP_Arms`

### 4.2 AnimGraph

```
状态机（或 Blend Poses by Enum）：
├── Idle Arms   ← 默认状态，手臂待机
├── Fire Arms   ← bIsFiring == true 时
└── Reload Arms ← bIsReloading == true 时

转换条件：
  Idle → Fire:   bIsFiring == true
  Fire → Idle:   bIsFiring == false（动画 Notify 回调设回）
  Idle → Reload: bIsReloading == true
  Reload → Idle: bIsReloading == false（BP_OnReloadStarted 设 true，C++ FinishReload 后 BP_OnAmmoChanged 里设 false）
```

变量来源：在 ABP 里新建两个蓝图变量 `bIsFiring` / `bIsReloading`（Boolean）→ BP_Player 的 `BP_OnFireEffects` 和 `BP_OnReloadStarted` 覆盖里，Get ArmsMesh → Get Anim Instance → Cast → Set 变量。

### 4.3 回 BP_Player 指定 ABP

ArmsMesh → Anim Class = `ABP_Arms` → 编译保存。

### 4.4 本步验证

PIE → 开火 → 手臂播射击动画 → 换弹 → 手臂播换弹动画。

## 第 5 步：BP_Weapon（武器蓝图）—— 1 小时

**目标**：开火/换弹的视觉表现 + 武器 Mesh + 枪口特效定位。

### 5.1 创建

1. Content/Code/Weapon/Base/ 右键 → Blueprint Class → Parent = **SightlineWeapon**
2. 命名 `BP_Weapon_Base` → 打开

### 5.2 Components（C++ 已自动创建，无需手动添加）

打开后 Components 面板里已有两个继承的组件——你只需要**调位置、配资产**：

```
BP_Weapon_Base（根）
├── WeaponMesh（Skeletal Mesh，C++ 注入）  ← 看得见的枪模型
│     只有骨骼模型能播动画(后坐/换弹/瞄准)
└── MuzzleSocket（Scene，C++ 注入）        ← 枪口坐标标记(无视觉)
      拖到枪管前端,特效从此冒出,自动跟随武器变换
```

| 操作 | 详情面板设置 |
|---|---|
| WeaponMesh → Skeletal Mesh | 选 BP_VIRTUS 的枪械骨骼模型 |
| WeaponMesh → Anim Class | 枪械动画蓝图（后坐/换弹动画，可选） |
| MuzzleSocket → 位置 | 在视口中拖到枪管前端（Transform → Location 微调） |

### 5.3 Details 配置（枪种参数 + 视觉资产）

| 属性 | 值 |
|---|---|
| Sightline\|Weapon → Fire Cooldown | `0.2`（每秒 5 发） |
| Sightline\|Weapon → Mag Size | `30` |
| Sightline\|Weapon → Reserve Ammo Max | `180` |
| Sightline\|Weapon → Reload Time | `2.0` |
| Sightline\|Visual → Default Skeletal Mesh | 枪械骨骼模型（BeginPlay 自动套到 WeaponMesh） |
| Sightline\|Visual → Default Anim Class | 枪械动画蓝图（可选） |

> **骨骼模型 vs 静态模型**：武器必须用骨骼网格——只有骨骼模型能播动画（开火后坐/换弹动作）。
> 子类（AK47/BP_VIRTUS）继承后各自指定自己的 Mesh+AnimClass+参数，开火逻辑一行不写。

### 5.4 表现钩子覆盖

**BP_OnFireEffects(MuzzlePos, Dir)**：

```
MuzzleSocket 的世界位置 → Spawn Emitter At Location（枪口火焰粒子）
Play Sound at Location（MS_VIRTUS 枪声）
Spawn Actor（BP_Casing，弹壳抛出）← 用旧蓝图的 BP_Casing 资产
```

**BP_OnReloadStarted()**：

```
Get Owning Character → Cast to BP_Player
→ Get ArmsMesh → Get Anim Instance → Set bIsReloading = true
Play Anim Montage（换弹蒙太奇，如有）或等待 C++ FinishReload 回调
```

**BP_OnAmmoChanged(InMag, Reserve)**：

```
Print String("弹药: " + InMag + "/" + Reserve)  ← M4 换成 UMG 弹药 UI
Get Owning Character → Cast to BP_Player
→ Get ArmsMesh → Get Anim Instance → Set bIsReloading = false  ← 换弹结束
```

### 5.5 BP_Weapon_VIRTUS（可选子类）

如果不同枪种有不同参数/模型：

1. Content/Code/Weapon/ 右键 → Blueprint Class → Parent = **BP_Weapon_Base**
2. 命名 `BP_Weapon_VIRTUS`
3. Details 覆盖：不同的 Fire Cooldown / Mag Size / 换不同的 Weapon Mesh

### 5.6 本步验证

PIE → 射击 → 看到枪口火焰+听到枪声+弹壳飞出 → 弹药 Print 正确 → 空仓自动换弹 → 换弹动画播完后弹药恢复。

## 常见问题

| 症状 | 原因 | 解法 |
|---|---|---|
| PIE 进游戏看不见自己 | ArmsMesh 的 `Only Owner See` 没勾 | Details → Rendering → Owner Only See = true |
| 远端人形不动画 | Anim Class 没指定或 ABP 的 Transition 条件没连 | 方案 A：确认 Anim Class = ABP_Manny；方案 B：检查状态机转换规则 |
| 远端人形不动（位置对） | Anim Class 没指定 | BP_RemotePawn Details → Mesh → Anim Class |
| 手臂和人形用不同骨架冲突 | 正常——两套独立 ABP 各走各路 | 不需要 Retarget，各自指定各自的 AnimClass |
| 开火没有枪口特效 | BP_OnFireEffects 没覆盖或 MuzzleSocket 位置不对 | 检查事件覆盖和 Scene 组件位置 |
| 换弹后弹药没恢复 | BP_OnAmmoChanged 没覆盖或 bIsReloading 没清 | FinishReload 会触发 BP_OnAmmoChanged，覆盖里 Set bIsReloading=false |
| 8 秒被踢 | Ping 定时器没起（不应出现——C++ 自动的） | 确认 bAutoLogin=true 且 ConnConfig 正确 |
| Engine Content 里找不到 SKM_Manny | 默认隐藏 | Content Browser 齿轮 → 勾选 Show Engine Content |
| 远端 Mannequin 是紫色的（缺材质） | 引擎 Mannequin 材质未随 Mesh 迁移 | 正常现象——M4 替换为正式角色模型后消失；或手动指定 Mannequin 材质 |
