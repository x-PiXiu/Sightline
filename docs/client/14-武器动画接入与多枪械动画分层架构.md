# 14 - 武器动画接入与多枪械动画分层架构

> 状态：方向已定稿，分期实施中
> 关联文档：11-远端傀儡动画同步方案 / 12-BP_LyPlayer换装与武器迁移执行手册 / 13-武器系统模块协作与数据流
> 本文回答两个问题：① ABP_Weapon_Rifle（枪本体动画）怎么接；② 角色动画围绕 Rifle 写死的问题怎么解（Animation Layers 分层架构）。

## 1. 结论速览

| 层 | 现状 | 换枪成本 |
|---|---|---|
| 协议 / 服务器 | 通用（flags bit0=开火，与枪种无关） | **零** |
| C++ 武器链（FireShot 播蒙太奇、AnimClass 注入） | 通用，全部数据从 Definition 读 | **零** |
| 枪本体（BP_Weapon_X + DA + ABP_Weapon_X） | 已数据驱动 | 新 DA + 新 BP 子类 + 新武器 ABP（结构照抄 DefaultSlot→Result），每把约 10 分钟 |
| **角色 ABP（ABP_Player_Manny）** | **写死 Rifle**——BS_Rifle_Locomotion_2D、BS_Rifle_Crouch、跳跃组、瞄准层的 MM_Rifle_Idle_Hipfire+AO 全部烘焙在图里 | 目前 = 复制整个 ABP，不可接受 → 用动画分层解 |

**方向**：角色 ABP 变薄壳，持枪姿势做成可插拔的**链接动画图层（Linked Anim Layer）**，每把枪一个小 ABP 实现同一接口；运行时装枪 `Link`、卸枪 `Unlink`。素材库原生就是这套架构（证据：`ALI_ItemAnimLayers` + `ABP_RifleAnimLayers_Feminine`）。

## 3. ABP_Weapon_Rifle 实施步骤（每步含作用与依据）

### 阶段 A：武器动画蓝图本体

**A1. 校验目标骨架 = SK_Rifle**
- 操作：双击 ABP_Weapon_Rifle → 工具栏看"目标骨架"。
- 作用：动画蓝图编译时将引用的动画资产与目标骨架匹配；`Montage_Play` 遇骨架不匹配**静默失败**（只有一条 Log，无报错弹窗）。
- 依据：C++ 链路 `SetAnimInstanceClass(AnimClass)` 注入到 `WeaponMesh`（骨骼网格资产 = SK_Rifle），动画实例类必须同骨架。
- 骨架错了 → 重建（新建动画蓝图时骨架选 SK_Rifle）。

**A2. AnimGraph 保持 `DefaultSlot(组 DefaultGroup) → 输出姿势`，不加任何其他节点**
- 作用：蒙太奇动画轨道必须经"插槽（Slot）"节点才能渲染到网格；蒙太奇声明槽 = DefaultSlot，ABP 里必须有同名插槽节点。
- 依据：`FireShot` 里 `Montage_Play(GunFireMontage)` 只负责触发，渲染路径由 ABP 插槽提供。
- 为什么不加混合空间/状态机/AO：武器网格的"待机"就是绑定姿势；武器动画只表达事件性动作（后坐/换弹），没有连续参数（速度/方向/俯仰），不满足混合空间的适用条件（连续参数→连续姿势），也不满足状态机条件（多状态迁移）。

### 阶段 B：Definition 数据装配

**B1. 步枪 Definition 填五字段**
- `AnimClass` = ABP_Weapon_Rifle
- `GunFireMontage` = AM_Weap_Rifle_Fire
- `GunReloadMontage` = AM_Weap_Rifle_Reload
- `ArmFireMontage` = AM_MM_Rifle_Fire
- `ArmReloadMontage` = AM_MM_Rifle_Reload
- 依据：C++ 全部从 Definition 按需读取（:61/:306/:382 与两个 BlueprintPure getter），不写死资产路径——这是 P8 数据驱动铺垫的直接收益。

**B2. 校验蒙太奇骨架与插槽**
- AM_Weap_* → 双击 → 左上骨架必须 SK_Rifle；AM_MM_* → 必须 SK_Mannequin。
- `AM_MM_Rifle_Fire` 左侧"插槽"轨道面板必须有 **DefaultSlot**（角色 ABP 插槽节点名）；若只有别的槽名 → 加 DefaultSlot 轨道并把片段拖入，否则"播了但看不见"。
- 依据：蒙太奇骨架必须与播放网格骨架严格一致；蒙太奇片段必须落在 ABP 中真实存在的插槽轨道上。

### 阶段 C：远端傀儡枪械表现（纯蓝图）

**C1. 傀儡武器组件必须为 SkeletalMesh 类型（SK_Rifle）**
- 作用：`Play Animation` 是 USkeletalMeshComponent 的函数，StaticMesh 没有。
- 依据：傀儡侧 C++ 无任何武器逻辑（代码检索证实 RemotePawn/Manager 零 weapon 引用），枪是编辑器手动挂的组件。

**C2. 上升沿检测 + PlayAnimation**
```
Event Tick → Sequence
  ├─ Then 0: AND( Get IsFiring , NOT Get LastFiring ) → Branch
  │            └ True → Play Animation(武器组件, Weap_Rifle_Fire, 不循环)
  └─ Then 1: SET LastFiring = Get IsFiring
```
- 作用（逐节点）：
  - `LastFiring`：缓存上一帧状态，构成边沿检测基准；
  - `AND(IsFiring, !LastFiring)`：只在 false→true 跳变帧为真。**必须用上升沿**——`PlayAnimation` 每次调用都从头播，若每帧调用，动画永远停在第一帧（定帧），这是此类接线的经典坑；
  - `PlayAnimation`：直接在组件上播序列，不需要动画实例类/ABP，傀儡侧零依赖。
- 依据：flags bit0 已由 SightlineRemotePawn 解码为 bIsFiring（Phase 1 C++ 已做），蓝图只做表现。
- 可选变体：想每发都抖 → 去掉上升沿，`Get IsFiring` 直接连 Branch（每帧重播等效于持续抖动，观感实测决定）。

### 阶段 D：手臂后坐蒙太奇（本地角色）

**D1. C++ 钩子 BP_OnShotFired（两处）**
- SightlineWeapon.h（BlueprintImplementableEvent 区，~109 行）：
```cpp
/** 每次开枪后调:BP 附加表现钩子(手臂后坐蒙太奇等,可空实现) */
UFUNCTION(BlueprintImplementableEvent, Category="Sightline|Weapon")
void BP_OnShotFired();
```
- SightlineWeapon.cpp FireShot：枪身蒙太奇块之后（原 307 行 `}` 后、309 行注释前）：
```cpp
    BP_OnShotFired();   // BP 表现钩子:手臂后坐等(可空实现)
```
- 作用：把"每一枪发生"暴露给蓝图。依据：换弹已有同类钩子 `BP_OnReloadStarted`，开枪缺位——补对称；放枪身蒙太奇之后保证先枪身后手臂的时序。

**D2. BP_Weapon_Rifle 事件图表**
```
Event BP_OnShotFired → Get Owner → Cast to SightlineCharacter
                                            └→ Play Anim Montage(Target=角色, Montage=Get Arm Fire Montage)
```
- 为什么在武器 BP 接：事件源在武器实例；蒙太奇数据就在 self 的 Definition 里，`GetArmFireMontage` 取值路径最短。
- `Play Anim Montage` = ACharacter::PlayAnimMontage（BlueprintCallable），走角色网格动画实例。
- 层次保证：角色 ABP 里插槽（DefaultSlot）位于分层混合之后 → **蒙太奇 > 瞄准层 > 自然动画**，播完自动回落持枪姿势；连发时每次重播 = 一枪一抖。

**D3. 换弹手臂蒙太奇（顺带）**
- BP_LyPlayer：`Event BP_OnReloadStarted` → `GetCurrentWeapon` → `GetArmReloadMontage` → `Play Anim Montage`（Target=Self）。
- 注意：只对本地玩家生效（傀儡不是 SightlineCharacter，且换弹状态未进同步协议）。

### 阶段 E：验证矩阵

## 4. 多枪械动画分层架构（方向归档）

### 4.1 目标拓扑

```
ABP_Player_Manny（薄壳,封版）
├── 底座:状态机 Movement(蹲/站 2D locomotion + 跳跃)——与枪种无关
└── 分层混合(spine_01↑)
      └── Layer 0 ← 【链接动画图层 WeaponPose】← 可插拔
             ├── 默认实现:MM_Rifle_Idle_Hipfire + AO_MM_Rifle_Idle_Hipfire(现链搬入)
             ├── ABP_WeaponPose_Pistol:MM_Pistol_Idle_ADS + AO_MM_Pistol_Idle_ADS(素材已在库)
             └── ABP_WeaponPose_Shotgun:MM_Shotgun_Idle_ADS + ...(素材已在库)

运行时:装枪  Link Anim Class Layers(DA.PoseLayer)
        卸枪  Unlink Anim Class Layers
```

### 4.2 第一期：泛化瞄准层（五步）

1. 建接口资产：右键 → 动画 → **动画图层接口** → `ALI_WeaponPose`，内定义姿势层函数 `WeaponPose`；
2. ABP_Player_Manny：分层混合 Layer 0 改为**链接动画图层节点**（接口=ALI_WeaponPose）；本 ABP 内创建同名图层函数作**默认实现**，现有步枪链原样搬入（不链接时行为不变）；
3. `USightlineWeaponDefinition` 加字段：`PoseLayer`（TSubclassOf\<UAnimInstance\>，EditAnywhere）；
4. 装枪钩子（BP_OnWeaponEquipped）里 `Link Anim Class Layers`，卸枪 `Unlink`；
5. 建首个新层 `ABP_WeaponPose_Pistol`（实现 ALI_WeaponPose，图=手枪 idle+手枪 AO）→ DA_Pistol.PoseLayer 指向它。

做完后：换枪 → 开枪姿势/瞄准俯仰自动跟随枪种；角色 ABP 从此封版。加新枪 = DA + BP_Weapon 子类 + ABP_Weapon_X + ABP_WeaponPose_X，**纯素材工作，零 C++**。

### 4.3 第二期：移动姿势族（打磨项）

手枪状态跑动的低姿感与步枪有差异——完整解法是 locomotion 混合空间族也走层交换（每枪一套 BS 链进层）。观感差异远小于上身姿势，先接受"移动底座共用"，不对劲再做。GAS 完整版即全部层化（AAA 成本）。

### 4.4 库内证据（为什么选这套架构）

- `Characters/Heroes/Mannequin/Animations/LinkedLayers/ALI_ItemAnimLayers` —— GAS 分层接口资产；
- `Locomotion/Rifle/ABP_RifleAnimLayers_Feminine` —— 步枪层实现 ABP；
- Pistol/Shotgun 全套姿势素材在 `Locomotion/Pistol`、`Locomotion/Shotgun`（Idle/ADS/AO/Jog/Walk/Jump 均有）。

注意：GAS 的 ABP_RifleAnimLayers_Feminine 依赖其自家接口与运动匹配系统，**不直接挂载**；只借架构思想，自建最小接口 ALI_WeaponPose。

## 5. 踩坑清单（本模块历史坑位）

| 坑 | 症状 | 根因/规避 |
|---|---|---|
| 蒙太奇骨架不匹配 | 枪/手臂完全不动，无报错 | Montage_Play 静默失败；每次填 DA 后双击蒙太奇核对左上骨架 |
| 插槽轨道名不符 | 蒙太奇"播了但看不见" | 蒙太奇片段必须在 ABP 真实存在的 Slot 轨道（DefaultSlot）上 |
| 每帧 PlayAnimation | 枪动画定格第一帧 | PlayAnimation 每调从头播；必须上升沿触发 |
| 傀儡武器 StaticMesh | PlayAnimation 节点不存在 | 必须 SkeletalMesh 组件 |
| 蓝图布尔直连 Weight | 姿势硬切闪变 | 布尔一律经 FInterp To 平滑成浮点权重再进动画节点 |
| GAS 层 ABP 直接挂 | 依赖缺失/大量告警 | 它耦合自家接口与运动匹配；只借架构不自挂 |
