### 1.3 房间生命周期现状

```
客户端连接 → C2S_Login → LoginAck(pid)
    ▼
C2S_JoinRoom(3) → RoomService::handleJoin
    ▼
findJoinableRoom() → 找到 WAITING 房 → addPlayer
                   → 找不到 → 创建新 Room(Waiting)
    ▼
playerCount >= min_players(2) → tryStart() → Playing
    ▼ (S2C_RoomStart 广播)
对战中...
    ▼
三杀判胜 → GameOverEvent + MatchEndEvent → Finished
    ▼ 5 秒
rematch() → Waiting → 人够自动再开
    ▼
玩家全走光 → 房间回收
```

**关键发现**：当前房间是**隐式创建**的——玩家发 JoinRoom 时如果没房就自动建。没有"显式建房"和"选房加入"的流程。协议号 22~25 已分配但服务端未实现。

```cpp
// RoomList(23)：[2B count] × N { [4B roomId][1B mode][1B cur][1B max] }
static void encodeEvent(const app::RoomListEvent& e, std::string& wire) {
    Writer w; w.u16(static_cast<uint16_t>(e.rooms.size()));
    for (const auto& r : e.rooms) {
        w.u32(r.room_id); w.u8(r.mode);
        w.u8(static_cast<uint8_t>(r.cur_players));
        w.u8(static_cast<uint8_t>(r.max_players));
    }
    finish(MsgId::S2C_RoomList, w, wire);
}

// RecordList(21)：[2B count] × N { [8B matchId][1B mode][1B win][2B kills][2B deaths] }
static void encodeEvent(const app::RecordListEvent& e, std::string& wire) {
    Writer w; w.u16(static_cast<uint16_t>(e.records.size()));
    for (const auto& r : e.records) {
        w.u64(r.match_id); w.u8(r.mode);
        w.u8(r.win ? 1 : 0); w.u16(r.kills); w.u16(r.deaths);
    }
    finish(MsgId::S2C_RecordList, w, wire);
}

// TopKills(27)：[2B count] × N { [8B accountId][2B kills] }
static void encodeEvent(const app::TopKillsEvent& e, std::string& wire) {
    Writer w; w.u16(static_cast<uint16_t>(e.rows.size()));
    for (const auto& r : e.rows) {
        w.u64(r.account_id); w.u16(r.kills);
    }
    finish(MsgId::S2C_TopKills, w, wire);
}
```

> **SHA-256 哈希**：UE 内置 `FSHA256::HashText` 不直接暴露给蓝图。
> 最简做法：C++ 加一个 BlueprintPure 静态方法到 SightlineProto：
> ```cpp
> UFUNCTION(BlueprintPure, Category="Sightline|Proto")
> static FString SHA256Hash(const FString& Input) {
>     FSHA256Signature Sig;
>     FSHA256::HashText(Input, Sig.GetBytes());
>     return Sig.ToString();
> }
> ```
> 需要 `#include "Misc/SHA256.h"`。蓝图搜 `SHA256 Hash` 即可调用。

## 九、实现状态更新（2026-09-22，客户端协议层补全）

### 9.1 本轮交付（客户端 UE 仓库）

| 项 | 内容 | 说明 |
|---|---|---|
| EncJoinRoom 升级 | `EncJoinRoom(int32 RoomId = 0)` | 空载荷 → `[4B roomId]`（0=自动匹配，加尾不改头）。**解锁建房闭环**：JoinAck 拿到 roomId 后发它进自己建的房 |
| 三个解码器 | `DecodeRoomList(23)` / `DecodeJoinAck(25)` / `DecodeRecordList(21)` | 直接吐 `TArray<FSightline*>`（下表三个 USTRUCT），蓝图 ForEach 即可填充 UMG 列表，**不再手工 DecodeU16/U32 算偏移** |
| 三个结构体 | `FSightlineRoomBrief` / `FSightlineJoinAck` / `FSightlineRecordRow` | BlueprintType，字段与服务端 dto.h 一一对应 |
| 协议修复 | `EncQueryRecord` 4B → **8B** | 服务端 `n < 8` 静默丢弃——此前战绩查询永远查不到（两端契约漂移，已钉进测试） |
| 自动化测试 | `FProtoDecodeLobby` | 字节级断言三解码器+截断防御，跑法同文件头（`Automation RunTests Sightline`） |

S2C 分发**无需改 C++**：`USightlineNetSubsystem::OnNetMessage(MsgId, Payload)` 已把 21/23/25
原样广播给蓝图，Widget 事件图表分支 msgid 即可。

### 9.2 蓝图接线修订（覆盖第四节对应段落）

- **收 RoomList(23)**：`DecodeRoomList(payload)` → `TArray<FSightlineRoomBrief>` → ForEach 填 RoomScroll（替代手工偏移解析）
- **收 JoinAck(25)**：`DecodeJoinAck(payload)` → Ok 为真 → **立即 `SendFrame(C2S_JoinRoom, EncJoinRoom(RoomId))`**（自动进刚建的房）；之后 RoomStart(4) 走既有开局流程
- **收 RecordList(21)**：`DecodeRecordList(payload)` → ForEach 填战绩列表（MatchId/Win/Kills/Deaths）
- **快速匹配按钮**：`EncJoinRoom(0)`（或无参默认）——语义同旧空载荷
- WBP_Login / WBP_MatchEnd / 切换控制器（第六节）步骤不变
