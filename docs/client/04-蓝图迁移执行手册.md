# 蓝图迁移执行手册（旧蓝图工作所在的机器）

> ⚠️ **本文已被 [05-蓝图从零搭建手册.md](05-蓝图从零搭建手册.md) 取代**——
> 基于 C++ 基类从零搭建比迁移不完整的旧蓝图更干净、学习价值更高、耗时相当。
> 本文保留为历史参考（了解"蓝图→C++ 迁移"的思路），新工程直接用 05。

> **定位**：本文是《03-客户端架构与C++基类设计》第五节的**执行版**——面向"纯蓝图网络方案(A~F)所在的机器"。

> **迁移哲学**：A~F 蓝图是设计上要被 C++ 取代的脚手架——删每一段图时，对照它变成的 C++ 代码，这次迁移就是一次最深的架构复习。
> **纪律**：迁移期间只在这台机器动蓝图（LFS 不能合并）；每步 commit；全部完成 push。

## 第 1 步：清除 BP_FPSPlayer 旧网络工作（先删图，不急着改父类）

**为什么它排第一**：它引用着 BP_RemotePawn 和所有旧变量——先删它，后面删除/重建别人时不会出失效引用警告。删除后蓝图回到"纯本地 FPS"状态，PIE 应能正常跑本地游戏（这也是验证"删除没伤到本地逻辑"的检查点）。

**删除清单**（Event Graph）：

| 删除项 | 内容 |
|---|---|
| BeginPlay 网络段 | Connect/Login/JoinRoom/两个 Bind/两个 SetTimer 全部节点（**保留**原有的输入设置/动画等本地初始化） |
| 自定义事件 | `OnServerMessage`（含全部分发 Branch 链）、`OnServerDisconnect`、`OnMoveTimer`、`OnPingTimer` |
| 变量 | `MyPlayerId`、`MyHP`、`IsDead`、`RemotePawnMap`、RTT 相关临时变量 |

**学习对照**：删每段时打开 C++ 对应物看一眼——

| 你删的蓝图 | 变成的 C++ |
|---|---|
| A：Connect+Login+JoinRoom | `BeginPlay → LoginToServer()` 6 行，配置进 `ConnConfig` 结构体 |
| B：Branch 分发链 | `OnServerMessage` 一个 switch，case 对应你的 Branch |
| Case 8 击杀双条件链（你修过 Bug 的地方） | `HandleHit` 里 `Shooter == MyPlayerId && bDead` 一行 |
| C/D 两个定时器 | `BeginPlay` 两行 `SetTimer`，Looping 语义一致 |
| F：Map/Spawn/Find/Remove | `RemotePawns` TMap + `SpawnRemotePawns/FindRemotePawn/DestroyRemotePawn` |

**本步验证**：编译 0 错误 → PIE 能进游戏、WASD 移动/开火特效正常（纯单机）→ commit。

## 第 2 步：BP_RemotePawn 删除重建（回答：可以，且推荐）

它迁移后零内容（组件/变量/插值全在 C++），删除重建比改父类干净（避开组件重名与变量冲突）。第 1 步已清掉唯一引用方，删除无警告。

```
① 内容浏览器 → BP_RemotePawn 右键 → Delete
② 同目录新建:Blueprint Class → Parent = ASightlineRemotePawn → 命名 BP_RemotePawn
③ 打开确认:Components 里已有 C++ 注入的 Mesh(骨骼网格组件),事件图全空
④ 编译保存(什么都不用连)
```

**可选配置**：Details → Mesh → Skeletal Mesh/Anim Class 指定角色模型与动画蓝图（需同一骨架）。先跳过也能跑（不可见但占位同步），M4 打磨时再配。

**学习对照**：你连的 `VInterpTo/RInterpTo` Tick 图 → `SightlineRemotePawn::Tick()` 约 10 行；蓝图 Tick 解释执行 vs C++ 原生指令——迁移完 `stat unit` 的 Game 时间变化就是证据。另有 `GetVelocity()` 覆写：`SetActorLocation` 不写引擎速度，动画蓝图的 Idle/Run 混合靠这个自算速度。

**本步验证**：编译 0 错误 → commit。

## 第 3 步：迁移 BP_WeaponBase（表现下沉）

```
① Class Settings → Parent = ASightlineWeapon → Compile
   └─ 若提示变量与基类冲突(弹药类同名):删蓝图侧变量,改用继承的 AmmoInMag/ReserveAmmo
② StartWeaponFire 的表现节点(弹壳生成/枪口特效/音效/动画通知 AN_Reload)
   → 复制进覆盖的 BP_OnFireEffects(MuzzlePos, Dir)   ← 参数即新开火事件的位置/方向
③ 删除:射线伤害判定段(服务器权威)、操作 E 加的 EncFire/SendFrame 段
④ 保留:BI_Fire 接口实现(内部改调 StartFire)、换弹的输入触发改调 C++ Reload()
```

**学习对照**：`EncFire + SendFrame(7)` → `FireShot()` 末尾一行 `Ch->ReportFire(Origin, Dir)`；且 C++ 在上报**前**有 `CanFire()` 检查——G5 死亡禁火从"两处蓝图各连一遍"变成"一处代码天然生效"。

**过渡说明**：本步完成后 IA_Fire 的旧调用链断了（射击暂不可用），第 5 步接回——两步之间不测试射击属预期。

**本步验证**：编译 0 错误 → PIE 进游戏本地移动正常 → commit。

## 第 4 步：迁移 BP_FPSPlayer（改父类 + 配置 + 网络“自动回来”）

```
① Class Settings → Parent = ASightlineCharacter → Compile
② Details 面板配置:
   RemotePawnClass = BP_RemotePawn          ← 第 2 步新建的
   ConnConfig.Host = <服务器地址>            ← 如 192.168.1.35 或 127.0.0.1
   ConnConfig.Port = 8888
   PlayerName     = UEPlayer(或自定义)
③ 编译保存
```

**此刻会发生什么**：什么都不用连——C++ `BeginPlay` 自动登录、自动起 10Hz 移动上报和 2 秒心跳、自动绑定消息路由。起服后 PIE，**登录/进房/移动/心跳/远端傀儡全部自动恢复**，这就是"状态与逻辑下沉"的直接体感。

**本步验证**：服务器（CLion 实例，debug 模式）日志出现 `conn#N in` + `msgid=1/3` → `msgid=5` 持续 + `msgid=10` 每 2 秒 → commit。

## 第 5 步：表现钩子接线 + IA_Fire 改道

**BP_FPSPlayer 事件图只加四条薄表现**（每条 2~3 个节点）：

| 钩子 | 连法 |
|---|---|
| `BP_OnLoggedIn(NewPlayerId)` | Print String("PlayerId:" + ToString) |
| `BP_OnRttUpdated(RttMs)` | Print String("RTT:" + ToString) |
| `BP_OnHitReceived(Shooter,Damage,NewHp,bDead)` | 分支 bDead → "你被击杀" / 否则 "受到X伤害 HP:Y" |
| `BP_OnRespawned(Pos,NewHp)` | Print String("重生 HP:" + ToString) |

（其余钩子 `BP_OnKillConfirmed/BP_OnGameOver/BP_OnKicked/BP_OnPlayerLeft/BP_OnDisconnected` 先留空，M4 按需补 UI。）

**IA_Fire 改道**：EnhancedInputAction IA_Fire → （原路径拿武器引用）→ 调 **StartFire**（替换原 StartWeaponFire 调用）。BI_Fire 接口实现内部同理。

**学习对照**：这四条钩子就是"四条铁律"第 2 条的落地——C++ `Handle*` 算完状态调钩子，蓝图只画效果。蓝图里从此没有一行判断逻辑。

**本步验证**：编译 0 错误 → commit。

## 常见问题

| 症状 | 原因 | 解法 |
|---|---|---|
| 改父类后编译报"变量与基类冲突" | BP 变量与 C++ 同名同型（变成覆写） | 删 BP 侧变量，用继承的 |
| PIE 没登录也没报错 | `bAutoLogin` 未勾或 `ConnConfig` 没配 | Details 检查；服务器日志确认有无 `conn#N in` |
| 登录成功但远端不生成 | `RemotePawnClass` 未设置 | BP_FPSPlayer Details 里指到 BP_RemotePawn（C++ 会打 Warning 提示） |
| 远端模型不动（位置对但不播动画） | AnimClass 没配,或动画蓝图 Cast BP_FPSPlayer 失败 | 配 AnimClass;动画蓝图改用 TryGetPawnOwner→GetVelocity（C++ 已覆写供速度） |
| 开火无 msgid=7 | IA_Fire 还在调旧事件,或武器未装备 | 检查第 5 步改道；`DefaultWeaponClass` 未配时蓝图需手动 EquipWeapon |
| 8 秒被踢 | 心跳停了 | C++ 定时器自动的——查是否误删 BeginPlay 后又自己加了逻辑 |
