## 讲述建议

- **每个案例都按"事故感"讲述**：先说现象（多严重/多诡异），再说排查（证据链），
  最后说方案与验证（数字对比）。不要一上来就说"我做了 XX 优化"。
- **每个案例都埋了一个"认知升级"**：01 → 测量系统本身会被污染；02 → GC 债务要还的；
  04 → 非阻塞 ≠ 多线程；05 → 变更扩散半径可测量。这是区分"做过"和"想明白"的关键。
- **服务器侧案例**（hitscan 判定、三红线架构、心跳惰性扫描）见
  [`../架构设计文档.md`](../架构设计文档.md)，本目录聚焦客户端与双端协作。
