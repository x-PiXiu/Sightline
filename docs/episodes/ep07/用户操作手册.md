## 1. 关卡布置：补 8~10 件掩体（约 30 分钟）

**目标**：给 人机的"绕路/躲掩体/墙后看不见"提供舞台。当前地图太空旷。

### 1.1 摆放（在 NewMap 关卡）

1. 打开 `NewMap` 关卡（Content Browser → `Game/Code/Map/NewMap`）；
2. 从 Content Browser 拖 **Basic Shapes/Box**（或 Cube）到场景，共 8~10 件。建议布局（参考，自由发挥）：
   - **中部 2~3 件**：1.5m~2m 高的箱子/矮墙（能完全挡住视线的）——走廊遮断；
   - **出生区附近各 1 件**：两个出生点（Spawn_1 ~ (442,-474)、Spawn_2 附近）各放一件可躲的箱子；
   - **边角 2~3 件**：诱导绕行路线（不要全摆在一条直线上）；
   - 尺寸参考：箱子 100~200cm 见方、高 100~250cm（比人高=挡视线；半人高=只挡子弹不挡视线，也可以混搭）。
3. **每一件都挂遮挡组件**（纪律：不挂=真人被 UE 物理挡、子弹穿墙、人机穿墙三不一致）：
   - 选中箱子 → Details → **Add Component** → 搜 `Sightline 遮挡标记`（SightlineOccluderComponent）→ 添加；
   - 组件默认"用包围盒"，无需调参数（和现有那面墙的做法一致）。
4. **放置出生点**（服务器权威重生的数据源）：
   - Place Actors 面板 → 搜 `Player Start` → 拖入场景；
   - **不要给出生点挂遮挡标记组件**（2026-11-03 实锤：4 个 PlayerStart 挂了标记件 → 出生点被烘成"箱子"→ 人机出生在箱里原地站桩+子弹打不中）。出生点进合同只认"类 + Spawn_{n} 命名"，挂标记件只会把自己变成遮挡物。烘焙器现在会自动忽略并打日志提醒；
   - **命名合同（关键）**：依次命名 `Spawn_1`、`Spawn_2`、`Spawn_3`、`Spawn_4`（内部名/标签/大纲名任一匹配即可，最稳的是**大纲里 F2 改名**）；
   - 摆放朝向：箭头指向场地中心；离墙 ≥100cm；彼此相距 ≥3m；**数量 = 4 个**——一个出生点只住一个人：满房 4 人（房主+3 人机）就要 4 个点。少于本局人数时，超出者叠在末位出生点（客户端胶囊互挤、零距互射），服务器开局会打 `[人机] 出生点不足` 告警（2026-11-03 联调实锤：原写"2 个起"是本手册的错）；编号连续不重复（同名会冲突）；
   - **掩体净空合同（2026-11-03 联调实锤新增，必守）**：掩体**箱缘离出生点 ≥70cm**（=命中体半径 34cm 物理净空 + 栅格膨胀 34cm + 余量）。箱子压住出生点的后果：人机出生在箱体内——导航起点格 blocked（原地不动、永远站桩）+ 视线/子弹都先穿箱皮（你永远打不中它）。防线：烘焙摘要红字 `[Spawn_N 压在盒#M]`（编辑器当场红字）+ 服务器启动告警 `[几何合同] 出生点 N 被掩体压住`；
   - **巡逻点（强烈建议）**：摆 2~4 个 **Target Point**，选中 → Details → Tags 加 `BotPatrol`——人机巡逻航点。不摆的话航点退化为出生点轮转（人机只在出生点之间转悠，画面单调）。摆同样守净空：不要落在掩体上。
   - *如果场景里已有叫 Spawn_1/Spawn_2 的 PlayerStart（ep03 时期的），直接复用调位置，再补 Spawn_3/Spawn_4。*

### 1.2 烘焙（把新掩体+出生点写进服务器合同）

1. PIE 进对局（和 ep05 时一样，烘焙跑在 PIE 世界里）；
2. 控制台（~ 键）输入 `SrvBakeOccluders` 回车；
3. **看输出摘要**（这一步的验收）：
   - 旧版只报盒数；**新版（M1 后我交付）会多两行**：`出生点=N`、`巡逻点=M`；
   - N 应等于你摆的 PlayerStart 数量；
4. 烘焙后 `server/assets/maps/NewMap.json` 会更新（git diff 可见 spawnPoints 字段）。

> ⚠ 注意：烘焙扩展（§2 交付后）才能导出出生点。所以顺序是：**先摆掩体（本节 1.1 可先做）→ 等我 M1/M2 代码 → 再跑 1.2 烘焙**。掩体部分随时可烘（现有命令就认）。

## 4. 动画迁移与 ABP（约 25 分钟·等 M5/M6 交付后做）

### 4.1 从 Lyra 迁移死亡/受击蒙太奇（Migrate 三步同 ep05 惯例）

1. 打开 Lyra 工程 `E:\workspace\Demo\UnrealDemo\LyraStarterGame`；
2. Content Browser 选中以下资产 → 右键 **Asset Actions → Migrate** → 目标选本项目 Content：
   - `Characters/Heroes/Mannequin/Animations/Actions/AM_MM_Death_Front_01`（先用 1 个，够演示；余 4 个方向死亡可选）
   - `Characters/Heroes/Mannequin/Animations/Actions/AM_MM_HitReact_Front_Lgt_01`（受击，可选）

### 4.2 ABP 加两个槽（ep06 教训：蒙太奇声明槽 ≠ ABP 槽节点）

已扫描确认声明槽：**死亡蒙太奇=FullBody 槽、受击蒙太奇=AdditiveHitReact 槽**——ABP 里现在都没有这两个节点，必须加，否则"播了听不见看不见"（换弹 UpperBody 那次的同款坑）：

1. 打开 `ABP_Mannequin` → AnimGraph；
2. 找到输出链最末端（现在是：…→ Slot(UpperBody) → TwoBoneIK → 输出）；
3. **在 TwoBoneIK 之后**串两个新 Slot 节点（拖入两次 Slot，下拉选现成项）：
   - `Slot(FullBody)` ——接 TwoBoneIK 输出；
   - `Slot(AdditiveHitReact)` ——接 Slot(FullBody) 输出；
   - 最后接输出姿势；
4. 编译保存。空闲时两个槽直通原姿势，零影响。

### 4.3 填 Class Defaults（BP_Character）

1. 打开 `BP_Character` → Class Defaults → **Sightline|Fire**（我交付的属性名）：
   - `Death Montage` ← AM_MM_Death_Front_01
   - `HitReact Montage` ← AM_MM_HitReact_Front_Lgt_01（可选）
2. 编译保存。
