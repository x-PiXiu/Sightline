# ep06 设计草案 ·「为什么你明明打中了，服务器说你没打中？」——延迟补偿回溯

> 军令状（ep05 S5-04 预告）：延迟补偿回溯——把你明明打中的那一枪，判回来。做不到，您扣我绩效。
> 状态：v1 草案（2026-10-30）——历史环归属/独立存储/单钟纪律三决策经用户会话校验（整洁架构 §7.6 + 体检四问全过）；RTT 通道/回溯上限两处待批（D6-01/D6-04）。

## 1. 根因与目标

**病灶**：客户端瞄的是**插值渲染点**（≈权威位 150ms 前 + 渲染延迟），服务器判的是**当前权威位**——300ms 滑块下两者错开一两米，明明瞄准了却打空。

**目标**：服务器在判定时，把所有目标回退到"射手开枪那一刻他们所在的位置"再求交——**服务器承认你眼睛看到的世界**。

**非目标（边界）**：
- 射手自身 19 号上报时滞（走动开枪弹孔偏下的另一半）不全解——ep06 修"目标历史"，射手侧外推留 ep07 契约演进评估；
- 多局并行仍不扩（ep03 既定边界，ep07 死亡重生时一起收）；
- 不做客户端 hit 回滚重放（客户端预测本期的表现已够，ep15 再谈）。

## 2. 方案总览：三步 + 一展示

```
① 每实体挂历史环（服务器接收时刻 + 钳后权威位 × 64 槽 ≈ 2.13s 窗口）
② 判定时刻参数化：Entity 记 shooterRtt（22 号上报），Fire 内部 judgeAt = nowMs − clamp(rtt, 0, 1000ms)——钳制策略归域层，适配层只透传事实
③ 判定射线查"历史插值位"：SampleHistoryAt 线性插值 → Pose 进 CastRay（本体零改动）
④ 客户端幽灵绘制：和解 HUD 加权威位行 + debug 开关（明暗双色同框）
```

## 4. 契约演进：22 号（MSG_IDS v4.3）

- **22 RTT_REPORT**（C→S · 1Hz · **6B**）：`[2B rttMs][2B upKB/s][2B downKB/s]`——客户端把 HUD 心跳 RTT（自己测得的 ACK 差）每秒报一次；**顺带预埋上下行带宽计数**（Connection 收发各挂字节计数器，每秒差分）——ep12 带宽统计钩子一次定稿零改动；
- 服务器 `MatchService::SetShooterRtt(pid, ms)` 存入 Entity（默认 0=未上报 → 不回溯，等价 ep05 行为）；带宽计数存调试面（ep12 消费）；
- 登记纪律照旧：先改 MSG_IDS.md 再动代码；帧格式 `[2B len][2B msgid][payload]` 小端不变；
- 旧客户端不报 22 号 → rtt=0 → 不回溯=完全向后兼容。
- **澄清（用户问"之前 RTT 消息号是多少"）**：此前**没有** RTT 消息——RTT 一直是客户端拿 2/3 号心跳对儿自测、只上 HUD 从不上报；22 为全新分配号（当前 msgid 最大=21，只增原则下 22 即下一个）。

## 8. KPI（大纲原文 → 采集协议已落地 2026-10-31）

300ms 滑块下移动靶命中率：**回溯关 vs 开** 双轮对比（各 30 发）——目标数字级对比。

**单变量口径（已实现）**：两轮唯一差异 = 客户端 `Sightline.RttReport` 开关（0=上报 rttMs=0 → 服务器 judgeAt=now 不回溯；1=正常上报）。滑块档位/巡逻靶/射手全同。判定日志带 `回溯=Nms` 字段，解析器按 N=0/N>0 自动分桶——不靠手动切日志。

**采集流程（单人，脚本机器人当靶）**：

1. 窗口 1：启动服务器（INFO 档）；
2. 窗口 2：`python3 server/scripts/bot_patrol.py` → 打印房间号 → 等待；
3. PIE 登录 → 加入该房间（机器人自动开局）→ 滑块设 300 → 机器人沿"射手→中心"纵深轴 ±350uu 正对射手跑近跑远（400uu/s·全程 7m，路线对齐 NewMap.json：最远点距墙西面 128cm 不穿模）；
4. 轮 A：PIE 控制台 `Sightline.RttReport 0` → **跟踪瞄准**（准星跟着跑近跑远的靶）按住左键 30 发 → 存服务器日志；
5. 轮 B：`Sightline.RttReport 1` → 同靶再 30 发 → 存日志；
6. `python3 server/scripts/parse_kpi06.py --server <日志>` → 两桶命中率对比。

回溯语义：跟踪瞄准下，回溯关=子弹追着 300ms 残影打（落点系统性落后靶身），回溯开=判定查历史环=指哪打哪。

解析器：`parse_kpi06.py`（分桶+拒绝旁注+射手过滤，合成日志已验证）；`bot_patrol.py` 首报即真值自选落点，真人加入后自动开局，180s 自动退出。
