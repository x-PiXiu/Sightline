## M2-A 输入资产（Content/Code/Input/）——已按 Code 规范就位

**步骤 1.0 建目录**
【操作】Content Browser 空白处右键 → New Folder → 命名 `Input`。
【作用】素材分目录是入库纪律（Lyra 内容已在 Content 根下占位，自产内容进独立目录方便 README 依赖说明）。

**步骤 1.1 建 IA_Move**
【操作】`+ Add`（内容浏览器左上绿色加号）→ Input → **Input Action** → 命名 `IA_Move` → 双击打开 → Details 面板 **Value Type** 下拉选 **Axis2D(Axis2D)** → Ctrl+S 保存。
【验证】Details 里 Value Type 显示 Axis2D。
【作用】WASD 四向要合成一个二维向量给 C++，一次绑定全拿。
【坑位】默认是 Boolean（只有 0/1），忘了改类型，WASD 就只剩"动/不动"没有斜向合成。

**步骤 1.2 建 IA_Look**：同上入口，命名 `IA_Look`，Value Type = **Axis2D**。
【作用】鼠标 XY 两个分量喂 Yaw/Pitch。
【坑位】同上。

**步骤 1.3 建 IA_Jump**：同上入口，命名 `IA_Jump`，Value Type 保持默认 **Digital(bool)**。
【作用】跳跃是开关量，bool 刚好。

**步骤 2.1 建 IMC 骨架**
【操作】`+ Add` → Input → **Input Mapping Context** → 命名 `IMC_Default` → 双击打开。
【验证】面板中出现 **Mappings** 列表（空的，带 + 号）。

**步骤 2.2 映射 W（前进）**
【操作】Mappings + 号 → 下拉选 `IA_Move` → 条目展开 → 点键位槽 → 按键盘 **W** → 展开条目的 **Modifiers** + 号 → 选 **Swizzle Input Axis Values**（轴序调整）→ 保持默认顺序 **YXZ**。
【验证】按住 W 时（PIE 里）C++ 收到 FVector2D(0, 1)——先不验，M2 末一起验。
【作用】键盘原始值在 X 轴（=1,0,0），Swizzle YXZ 把它挪到 Y（=0,1,0）= 前进分量。
【坑位】W 不加 Swizzle 是最常见错——症状：按 W 角色往右走。

**步骤 2.3 映射 S（后退）**：加 `IA_Move` → 按 **S** → Modifiers：先 **Swizzle Input Axis Values**（YXZ）再 **Negate**（取反）→ 结果 (0,-1)。
【坑位】两个修饰符有顺序，先 Swizzle 后 Negate（先把值挪到 Y 再取反）。

**步骤 2.4 映射 D（右移）**：加 `IA_Move` → 按 **D** → 不加任何修饰符 → 键盘原始值 (1,0,0) 恰好就是右移。
**步骤 2.5 映射 A（左移）**：加 `IA_Move` → 按 **A** → Modifiers：**Negate** → (-1,0,0)。
【坑位】A 别加 Swizzle（加了就成"后退"）。

**步骤 2.6 映射鼠标**：加 `IA_Look` → 点键位槽 → 下拉搜 **Mouse XY 2D Axis**（鼠标二维轴）→ 先不加修饰符。
【坑位】抬头/低头方向反了 = 鼠标 Y 符号问题，回来给这条加 **Negate（只勾 Y）**，不动相机代码。

**步骤 2.7 映射空格**：加 `IA_Jump` → 按 **Space Bar**。
【验证总闸】M2 步骤 18 后 PIE 里：WASD 八方向动、鼠标转视角、空格跳——全对 = M2-A 完工。

## M2-B 角色资产（Content/Code/Character/）

**步骤 3 建目录 + 两个 BP 子类**
【操作】在 `Code/Character` 文件夹内 → `+ Add` → Blueprint Class → 弹窗 **Pick Parent Class** → 切 **All Classes** 标签 → 搜 `SightlineCharacter` → 选中 → 命名 `BP_Character_Manny` → 再来一次命名 `BP_Character_Quinn`。
【验证】双击打开，组件面板里能看到 Mesh / CollisionCapsule / Camera（P1 已建）。
【作用】皮肤引用留资产层；两个子类逻辑 100% 共享，只有网格体不同——"自己=Manny/远端=Quinn"在此分叉。
【坑位】All Classes 里搜不到 = P1 没编译进工程，回炉。

**步骤 4 换网格体**
【操作】双击 `BP_Character_Manny` → 组件面板选 **Mesh**（名字就叫 Mesh）→ Details 搜 `Skeletal` → **Skeletal Mesh Asset** 下拉选 `SKM_Manny`。`BP_Character_Quinn` 同法选 `SKM_Quinn`。
【验证】视口里角色从灰色占位变成有贴图的模型；骨架显示为 SK_Mannequin。
【作用】确认双角色同骨架——"一套动画服务所有角色"的物理前提。

**步骤 5 挂动画蓝图**（先跳过，做完步骤 7 回来）
【操作】Mesh 的 Details → **Animation Mode** 下拉 = **Use Animation Blueprint** → 出现 **Anim Class** 下拉 → 选 `ABP_Mannequin`。两个 BP 都挂。
【验证】选中 Mesh，Details 里 Anim Class 显示 ABP_Mannequin。
【作用】双角色挂同一个动画类——"全项目唯一 ABP"的落点。

**步骤 6 相机目检（静态预览，不进 PIE）**
【操作】BP_Character_Manny 的 **Viewport** 视口左上角 → **Lit 下拉旁的相机图标下拉（Perspective）** → 菜单 **Cameras** 分组 → 点 `Camera` → 视口切为透过相机看到的画面；看完切回 **Perspective**。
【验证】① 数字硬校验：选中 Camera → Details → Relative Location **Z = 75**（88 半高 + 75 = 离地 163cm 标准眼高）；② 预览画面在眼睛高度，能看到**预览场景**（灰地板）的地面。
【作用】第一人称沉浸基线；相机错位，后面手感分全失真。
【坑位】相机别加 SpringArm（第三人称做法）；蓝图编辑器里看到的是预览场景不是 L_Arena；身体模型从相机看穿模/隐形是正常现象（OwnerNoSee + 单面网格），不是 bug；停在相机视角会转不动视角——记得切回透视。真正的动态验证（跑/跳/AO）在步骤 19 后的 PIE。
【中文界面对照】透视图 = Perspective ｜ 光照 = Lit ｜ 摄像机 = Cameras（相机预览就藏在"透视图"下拉的"摄像机"分组里）。

## M2-C 动画蓝图 ABP_Mannequin（创建后 Move 到 Content/Code/Character/，本期最大工程）

**步骤 7 创建**
【操作】Content Browser 右键 `SK_Mannequin` 骨架资产 → Animation → **Animation Blueprint** → 弹窗：Parent Class 选 `AnimInstance`（P2 交付了就选 USightlineAnimInstance）、Target Skeleton 选 `SK_Mannequin` → 命名 `ABP_Mannequin`。
【验证】打开后上方有三个标签：**Event Graph** / **Anim Graph** / 右侧 **Asset Browser**（能列出所有 SK_Mannequin 动画）。
【作用】绑骨架=安全（错误的网格体挂上来编辑器直接报错）；Asset Browser 列出的就是"能用的全部素材"。

**步骤 8 建变量 + 每帧取值**
【操作】
1. My Blueprint 面板 → Variables 区 + 号，依次建 5 个变量：`Speed`(Float)、`DirectionAngle`(Float)、`Pitch`(Float)、`bFalling`(Boolean)、`WeaponType`(Byte)；
2. 切 **Event Graph** 标签 → 已有 `Event Blueprint Update Animation` 节点 → 从它拉线 → 搜 `Try Get Pawn Owner` → 再拉线 → 搜 `Cast To SightlineCharacter` → 从 As Sightline Character 引脚拉线 → **Get AnimInputs** → 拉线选 **Break FAnimInputs**（结构体自动拆出 Speed/DirectionAngle/Pitch/bFalling/WeaponType 五个引脚）→ 分别连到 5 个 **Set 变量** 节点。
【验证】编译（左上 Compile）无红；预览窗口给 Speed 手动赋值能看到变量面板数值变化。
【作用】**ABP 只吃 Character 喂的数，图内绝不读 GetVelocity / IsFalling**——远端直设位置速度恒零，读引擎值远端永远播 Idle（"对端卡死"假象的根源，§2.4 第一坑）。

**步骤 9 搭状态机骨架**
【操作】切 **Anim Graph** → 右键空白 → **Add State Machine** → 命名 `Locomotion` → 双击进入 → 右键空白 → Add State ×5，命名：`Idle`、`WalkRun`、`Jump_Start`、`Jump_Fall`、`Jump_Land`。入口箭头连 `Idle`。
【验证】图里有六个节点（Entry + 5 状态）。
【作用】状态机是"角色在干什么"的唯一真相源。

**步骤 10 填每个状态的动画**
【操作】双击 `Idle` 进入 → 从右侧 Asset Browser 拖 `MM_Unarmed_Idle_Ready` 进图 → 自动生成播放节点 → 连到 **Result**。`WalkRun` 状态里拖 `BS_Unarmed_Move`（自建混合空间，步骤 12 建它并处理输入；若先做本步，先占位、步骤 12 后替换）。`Jump_Start` 拖 `MM_Unarmed_Jump_Start`、`Jump_Fall` 拖 `MM_Unarmed_Jump_Fall_Loop`、`Jump_Land` 拖 `MM_Unarmed_Jump_Fall_Land`。
【验证】每个状态里 Result 有姿势连入，Compile 不报缺连线。
【作用】Idle=呼吸感、WalkRun=8 向走位、Jump 三段=起跳/滞空/落地不瞬变。

**步骤 11 写转移规则（唯一要动脑的图逻辑）**
【点击地图】状态间连线上的**小箭头图标 = 一条转移规则**：**单击选中 → 右侧细节面板出属性**（Automatic Rule 复选框在这）；**双击 → 打开该转移的规则图**（迷你事件图，中央红色 **Can Enter Transition / 可以进入转换** 结果节点）。一句话：**单击调属性，双击写逻辑**。箭头小就滚轮放大视图，悬停会高亮。
【操作】两种写法逐条配：
- Idle → WalkRun（写法 A·条件型）：双击箭头 → `Get Speed` → `>` → 常量 5 → 连 Can Enter Transition；
- WalkRun → Idle（写法 A）：`Get Speed` → `<` → 常量 2 → 连入（**滞回带**：5 与 2 故意不同，防阈值抖动）；
- Idle/WalkRun → Jump_Start（写法 A）：`Get bFalling` → 连入；
- Jump_Start → Jump_Fall（写法 B·时间型）：**单击**箭头 → 细节面板勾 **Automatic Rule based on Sequence Player in State**（源状态动画播完自动走，规则图留空）；
- Jump_Fall → Jump_Land（写法 A）：`Get bFalling` → NOT → 连入；
- Jump_Land → Idle（写法 B）：勾 Automatic Rule（落地动画播完自动回）。**已知取舍**：移动中落地会短暂经 Idle 再回 WalkRun（多一帧切换），M2 接受，ep14 加 Jump_Land→WalkRun（Speed>5）转移修掉。
【验证】Compile；工具栏 **类默认值** → 把 `Speed` 默认值改 30 → 编译 → 预览角色走起；改回 0 → 回 Idle（滞回带两阈值就验完了）。Jump 链留给 PIE 真按空格验。
【作用】滞回与动画时长驱动全部是表现层自有规则，不加一个 C++ 标记——蓝图合法岗位的样板。

**步骤 12 混合空间：弃 BS_MM，自建 BS_Unarmed_Move（校验点已命中，2026-10-15 实测）**
【校验结论】`BS_MM_Unarmed_Jog_Walk` 实测为**单轴**（Speed 200~400，仅 Jog/Walk 两采样）——Lyra 原意是走/跑两档过渡，扛不起 8 向走位；且我们 WASD 恒速 500，永远钳在 Jog，Walk 采样永不出现。
【解法】方向循环素材 8 向全在库里 → **自建 BlendSpace 2D，轴由我们定义**（C++ DirectionAngle 符号约定就此成为标准，首日校验点关闭）：
【操作】
1. `+ Add` → 动画 → **混合空间 2D** → 骨架 `SK_Mannequin` → 命名 `BS_Unarmed_Move` → Move 到 `Code/Character`；
2. 资产详情 Axis Settings：水平 = `Speed`（0~500 · 分割 4）；垂直 = `Direction`（-180~180 · 分割 4）；
3. 图表拖入 **6 采样**并填坐标（对角方向 = 相邻锚点插值混合，45°=50%前+50%右，行业标准做法）：`MM_Unarmed_Walk_Fwd`@(200,0) ｜ `MM_Unarmed_Jog_Fwd`@(400,0) ｜ `MM_Unarmed_Jog_Right`@(400,90) ｜ `MM_Unarmed_Jog_Left`@(400,-90) ｜ **`MM_Unarmed_Jog_Bwd`@(400,180) 与 `MM_Unarmed_Jog_Bwd`@(400,-180)（同一动画占两锚——Direction 轴不环绕，缺 -180 侧会让左后步偏左移）**。（可选 Walk_Left/Right/Bwd @200 加速过渡帧）
【验证】Ctrl+点图表不同坐标，四向循环+走跑过渡都出。
【作用】"远端向左=向左动画"的执行器；轴定义权收回我们手里，C++ 与资产零猜谜。
【坑位】原 BS_MM 不删不改（素材零修改纪律）；WalkRun 状态里**换拖 BS_Unarmed_Move**，Speed→X、DirectionAngle→Y。

**步骤 13 叠加瞄准偏移层（2026-10-15 实测定版：5.7 的 AO 节点自带 Base Pose 脚，无需 Dynamic Additive 组合）**
【操作】
1. AnimGraph 主层：状态机输出引脚右键 → **Save Cached Pose** → 命名 `LocoPose`；
2. 右键空白 → 搜 `Aim Offset` → 添加 `AO_MM_Unarmed_Idle_Ready` 节点；
3. **三线接法**：LocoPose 的 Pose 输出 → AO 的 **Base Pose** 脚；变量 `Pitch` 接 AO 的 **Pitch** 脚（Yaw 暂留 0——ep05 瞄准再用）；AO **姿势输出** → 继续后续层；Alpha 保持 1.0；
4. AO 输出与 Result 之间插 **Slot 'UpperBody'** 节点（步骤 14 的入口，本期直通）。
【验证】编译 → 类默认值 → Pitch 改 30/-30 → 预览角色抬头/低头、腿保持站姿；改回 0。
【作用】抬头低头跟手（远端看你的俯仰 = 网络 Pitch 驱动这条层）；AO 节点内部完成 additive 叠加，不覆盖步态。
【坑位】先双击 AO 资产确认是 AimOffset 类型（2D 网格编辑器）；5.7 的 AO 播放器节点**自带 Base Pose 输入脚**——若您的版本没有这只脚，才退回"Make Dynamic Additive + Apply Dynamic Additive"两件套配方（Base=LocoPose、Additive=AO 输出）；接不上就截图发我。

**步骤 14 接 Slot 出口**
【操作】**AO 节点的姿势输出** → 右键 → 搜 **`Slot`**（节点名就叫 Slot/插槽——**不是 "Add Slot"，那是我要说的动词**）→ 点 **Slot** 节点 → Details 里 **Slot Name** = `UpperBody`（下拉有就选，没有就手输回车）→ 连 **Result Pose** → Compile & Save。（最终链：LocoPose → AO(Base Pose) → AO 输出 → Slot → Result——无任何 Additive 节点，见步骤 13 实测定版。）
【验证】预览窗口全链目检（步骤 10~14 一起过）：Idle 呼吸 / 四向走跑 / 跳三段 / Pitch 抬头低头 / Slot 直通。
【作用】蒙太奇入口留位——ep05 的 Fire/Reload 从 C++ `PlayAnimMontage` 打进这个 Slot，图零改动；本期无蒙太奇时直通。
【坑位】Slot 名固定 `UpperBody`，ep05 蒙太奇的 Slot 设置必须逐字同名，否则无声失效。

## M2-D GameMode 与关卡

### 关卡地形/地图资源从哪来（专节回答）

三条路，本期走路线一：

| 路线 | 是什么 | 结论 |
|------|--------|------|
| **一 · 引擎模板 + 几何体**（推荐） | `File → New Level` 的 Basic 模板（自带地板/光照/PlayerStart）+ Place Actors 拉 Cube 搭场地，材质可用**引擎自带 Starter Content**（内容浏览器 `+ Add` → Feature Pack → Starter Content，启用后得现成材质/楼梯/坡道，零下载零外网） | ✅ 本期走这条：零新依赖、两小时完工 |
| 二 · Fab 商城资源 | Epic 官方 Fab（启动器内进）有免费 Megascans 扫描素材和示例场景 | ⏸ ep05+ 想好看再说：要 Epic 账号下载（走代理）、且按总纲 2.4.1 纪律要记进 README 依赖说明，和"控制变量"教学目标相性差 |
| 三 · Lyra 的地图 | ❌ 不碰：库里只有角色/武器子集，Lyra 关卡会牵出 GAS/GameFeatures 全家桶依赖——正是总纲点名的泥潭 | ❌ |

**为什么几何体反而是对的**（写进口播）：同步测试关卡需要的是**高对比参照物**，不是地形美术——棋盘格地板是最好的"位移测量纸"，掩体是"撞/绕"的参照物；均匀的漂亮地形反而看不出拉扯和瞬移。粗糙即是人设（总纲：能用且正确就是卖点）。Landscape 真实地形系统本期不需要。

**步骤 15 建 GameMode**

## M2-E RoomListText 富文本升级（C++ 已入库 · 编辑器三步）

**步骤 E1 建字体资产 Font_Mono**
【操作】
1. Content Browser 导航到 `Code/UI` → 新建子文件夹 `Fonts` → 进入；
2. Windows 文件管理器地址栏输 `C:\Windows\Fonts` → 搜索 `consola` → **拖动的是字体家族图标（含常规/粗/斜/粗斜 4 个文件）** → UE 每个文件生成 1 FontFace + 1 Font = **8 个资产，属正常**；名册只用常规体：把 **`CONSOLA_Font` 改名 `Font_Mono`**，删除其余 6 个（CONSOLAB/CONSOLAI/CONSOLAZ 各自的 FontFace 与 _Font 包装，无引用可安全删）；head/full 的 Bold 勾选保留但渲染为常规字重——层级靠颜色/字号已足够，真粗体 ep14 再拖 consolab.ttf 重建；

4. Ctrl+S。
【验证】Details 无报错：Default Family=Consolas、Sub Families=1 条 Default→中文；最终验证在 E3 后的 PIE——名册中文非 □ 且数字列对齐。
【作用】Consolas 管数字等宽（列锚对齐的物理前提），中文靠回退链补——合成"数字等宽 + 中文可读"复合字体。
【坑位】搜字体文件用文件名 `consola`；忘挂回退链 = 中文全 □；【保存规范】`Code/UI/Fonts`。

**步骤 E2 建样式表（DataTable of RichTextStyleRow）**
【操作】先把 Content Browser **导航进 `Code/UI`**（创建位置=当前浏览文件夹，出生即在对的地方）→ `+ Add` → 顶部搜索 `data table` → 选 **Miscellaneous** 下的 **Data Table** → 弹窗 **Pick Row Structure** → 搜索框输 `Rich`（**一个单词，内部名无空格**；此处搜索的不是 + Add 菜单）→ 选 **RichTextStyleRow** → 命名 `RTS_Lobby` → 双击打开 → **Add** 三行：
- `default`：Font_Mono · Size 40 · 颜色 #333333（正文）
- `head`：Font_Mono · Size 30 · Bold · 颜色 #999999（表头）
- `full`：Font_Mono · Size 40 · Bold · 颜色 #C8161D（满员行）
（数值依据：行宽随字号线性放大，Font 40 时整行 1080px ≤ 面板 1160px 为列锚天花板；视频可读性优先。十六进制→RGB：#333333=R51 G51 B51；#999999=R153 G153 B153；#C8161D=R200 G22 B29——填 Color and Opacity 时用）→ Ctrl+S。
【作用】这张表是 RichText 标签的"翻译字典"：C++ 吐 `<head>`/`<full>` 标签 → 控件按行名查表取字体/字号/颜色渲染；调色只改表不碰代码。
【坑位】搜不到时先重启编辑器刷结构注册表；RichTextStyleRow 在 UMG 模块、选择器无过滤障碍（已查 5.7 引擎源码确认）。建错了文件夹就右键 → **Move** 移到 `Code/UI`（别用复制）。
【作用】C++ 里的 `<head>` / `<full>` 标签按行名查这张表——**行名与标签逐字一致**，样式（字体/字号/颜色码）随便调不碰代码。

**步骤 E3 WBP_Lobby 换控件**
【操作】打开 WBP_Lobby → 删除旧 `RoomListText`（Text Block）→ 同位置拖 **Rich Text Block** → 命名 `RoomListText`（逐字）→ Details：**Text Style Set** = `RTS_Lobby`、**Default Text Style** = `default`、**Auto Wrap Text** = 不勾（C++ 已强制关）。
