**对拍测试期间实锤的四个真实语义**（测试设计教训，入册）：
1. **首报不写历史环**——UpdateEntity 的 else 分支才 push；victim 仅首报一次→`SampleHistoryAt` nullopt→永远无候选（`nearPid=0` 实锤）→victim 须第二拍上报
2. **跨房隔离是正确行为**——不同房实体互不出现在对方候选集（测试脚本曾把交战双方放两房→设计错误）
3. **跨 shard 事件无全局序**——完成信号（本房 EL）早于他房 MS 到达是合法调度；测试完成条件须"两房事件都到齐"
4. **respawnDelayMs 是 uint16**——配置 600000 截断=10176（mod 65536），配置上界须进 Validate
