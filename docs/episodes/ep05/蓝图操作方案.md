## 0. C++ 前置清单（AI 实习生交付，编辑器操作的地基）

| # | 交付物 | 谁依赖它 |
|---|--------|----------|

| P3 | 角色侧表现接口：`PlayFireMontage()`（C++ 播 AM_MM 蒙太奇由蓝图定——**C++ 不硬引用 Lyra 资产路径**，蒙太奇资产由蓝图子类ExposeForDefaults 或 BP 调用，保干净 checkout 可编译） | 步骤 6 |
| P4 | tracer（可选增强）：OnFireResult 里 `ULineBatchComponent::DrawLine`（Muzzle 挂点 → HitPoint，0.15s 淡出，Debug 线即可——开发观感糙但真，D5-05） | 步骤 10（可选） |
| P5 | 弹药/换弹状态：本地模拟字段 + `OnLocalReload()` 委托（本期无 UI，ep07 接 HUD；留口不实现 UI） | ——（纯 C++，编辑器零操作） |
| P6 | `USightlineOccluderComponent`（**运行时零逻辑标记件**：可选自定义包围盒覆盖/偏移）+ 烘焙入口 `Srv.BakeOccluders`（Exec/Editor Utility 调静态 BakeLib：扫组件→枚举简单碰撞原语→写 `server/assets/maps/NewMap.json`，含 entityHitbox 胶囊真身） | M5-F |

**红线**：C++ 全程不出现 `/Game/Weapons/...` 硬路径——Lyra 素材不入库，硬引用 = 干净 checkout 编译爆炸。资产引用只住蓝图（.uasset 不入库，按本方案重建，ep03 同纪律）。

**资产引用分层（2026-10-24 立）**：①**硬引用**（蓝图默认值/组件配置）= 本方案现状用法——可用前提是 BP 与 Lyra 同居 Content 且 BP 不入库，依赖链问题只属于 C++ 和打包 cook；②**软引用**（TSoftObjectPtr）= **可能缺席的资产专用**（加载失败静默降级不崩）——火光 Niagara 用它；③**数据驱动**（武器配置 DataAsset/DataTable）= **现在不上**，触发点=第 7 期第二把武器（届时 20 号加 weaponType 字段，契约 v4.2+ 演进）——单武器上配置表是给观众演示过度设计（D5-11）。

## M5-A 输入资产（Content/Code/Input/）

**步骤 1.1 建 IA_Fire**
【操作】`+ Add` → Input → **Input Action** → 命名 `IA_Fire` → Value Type 保持 **Digital(bool)** → Ctrl+S。
【作用】开火是开关量：按下=请求一次，不是按住持续（连发节奏由本地节流管，ep08 外挂期再演"按住硬灌"）。
【坑位】别建成 Axis1D——按住会每帧触发，本地节流白写。

**步骤 1.2 IMC_Default 加映射**
【操作】双击 `IMC_Default` → Mappings + → IA_Fire → 键位 **Left Mouse Button**。
【验证】IMC 列表出现 LMB → IA_Fire。
【坑位】ep03 的 IA_Look 若绑了鼠标移动，别覆盖——IMC 里是并列条目不是互斥。

## M5-B 持枪（BP_Character_Manny / BP_Character_Quinn 各做一遍）

**步骤 2.1 加枪组件**
【操作】双击 `BP_Character_Manny` → Components + → **Skeletal Mesh** → 命名 `WeaponRifle` → Details 选 Skeletal Mesh = `SK_Rifle` → AnimClass 留 **None**。
【作用】SK_Rifle 是 Lyra 步枪骨骼网格；本期枪不自带动画实例（枪蒙太奇可选增强见步骤 2.4），None 即可播默认姿态。
【坑位】选成 `SM_Rifle`（静态版）就没法播枪蒙太奇、也没 Muzzle 挂点了。

**步骤 2.2 挂到右手**
【操作】选中 WeaponRifle → Details → Parent Socket = **weapon_r**。
【验证】视口里枪贴到右手；位置歪了调 Details → Transform（先记 0，游戏里再修）。
【坑位】①weapon_r 是**骨骼挂点**不是组件挂点，下拉里在 skeleton 分区；②Manny/Quinn 两套 BP 都要做，漏一个=双开一边没枪。

**步骤 2.3 相机穿模检查**
【操作】PIE 站定看自己的枪。
【坑位】相机在 (18,0,82) 贴头部，近端手臂/枪管可能穿脸——ep05 口径"粗糙即人设"不修相机；真碍眼就给 WeaponRifle 设 **OwnerOnlySee 关掉**再评估（别改相机位，动了 ep03 的基准）。

**步骤 2.4（可选增强）枪蒙太奇**
【操作】WeaponRifle → Details → Animation Mode = **Use Animation Asset** → Anim to Play 留空；如需开火枪动：蓝图里 `Play Animation (Montage)` = `AM_Weap_Rifle_Fire`（挂 SK_Rifle_Skeleton，已核）。
【作用】枪械自己的后坐动画。
【坑位】**AM_MM_Rifle_Fire 挂的是角色骨架**（已核 name table），别在枪上播它——骨架不匹配直接不播且无报错，表现为"枪没反应"。

## M5-C 角色开火动画（ABP 加槽 + 蒙太奇）

**步骤 3.1 ABP_Mannequin 加 UpperBody 槽**
【操作】双击 `ABP_Mannequin` → AnimGraph → 在最终姿势输出**之前**插入 **Slot 'UpperBody'**（右键 → Slot → 槽名填 UpperBody）→ 若 AnimGraph 没有 Slot 节点缓存，先在 Class Defaults / Asset 的 **Slot Groups** 里登记（Animation Blueprint 面板 → Slot Nodes 区新建 UpperBody，组默认 None）→ 保存。
【验证】AnimGraph 输出链上能看到 Slot 'UpperBody' 串在 Locomotion 之后。
【作用】开火蒙太奇只走上半身槽，跑动不被打断。
【坑位】槽名必须和蒙太奇 Slot 名逐字符一致（下一步），大小写都算。

**步骤 3.2 蒙太奇槽位对齐**
【操作】双击 `AM_MM_Rifle_Fire`（只读资产不能改——**不能改 Lyra 原件**）。
【坑位——这是本方案最大的坑】Lyra 原蒙太奇的 Slot 是它自己的插槽名（Lyra 体系），我们 ABP 的 UpperBody 槽接不住它。**解法：自建包装蒙太奇**——`+ Add` → Animation → **Montage** → 骨架选 `SK_Mannequin` → 命名 `AM_Code_Rifle_Fire` → 打开 → Section 里 **New Slot = UpperBody** → 把 `AM_MM_Rifle_Fire` 作为 **Animation Section / Montage 段插入**（右键蒙太奇时间轴 → Add Animation Section → 选 AM_MM_Rifle_Fire 的动画资产）→ 保存到 `Content/Code/Character/Animation/`。
【验证】AM_Code_Rifle_Fire 时间轴上有一段动画 + 一个 UpperBody 槽节点。
【作用】Lyra 动画数据 + 自管槽位，原素材零修改。
【坑位】直接 PlayAnimMontage(AM_MM_Rifle_Fire) 大概率无声无息不播（槽对不上）；先自建包装再播，一劳永逸。

**步骤 3.3 C++ 触发（等 P3）**
【操作】BP_Character_Manny → Class Defaults → 把 `AM_Code_Rifle_Fire` 填进 P3 暴露的 ExposeOnSpawn/Defaults 字段（如 `FireMontage`）。
【验证】PIE 开枪：角色上身抬枪、松开回 locomotion，跑动中开火不打断腿部。
【坑位】若上身槽播了但角色瞬回原姿势——蒙太奇混合出时间太短，包装蒙太奇 BlendOut 调 0.2s。

## M5-D 准星 + 命中反馈 UI（Content/Code/UI/）

**步骤 4.1 WBP_Crosshair**
【操作】`+ Add` → User Interface → **Widget Blueprint** → 命名 `WBP_Crosshair`（挂 `URoomWidgetBase`? 不——准星无逻辑，挂 **UserWidget 裸基类**即可）→ Designer：Canvas Panel 居中放 4 条细 Image（上下左右短线，白色 40% 透明）。
【作用】开火方向参照物——玩家瞄哪，射线从相机沿视线走。
【坑位】别做成大十字准星贴图——先 4 条 Image 凑，ep14 手感打磨期再换图。

**步骤 4.2 挂进对局 HUD**
【操作】对局期 UI 挂载点（与 WBP_DebugPanel 同处，PIE 对局期 AddToViewport 的那个位置）加一行：Create Widget WBP_Crosshair → Add to Viewport（ZOrder 低于 DebugPanel）。
【验证】进对局见准星，回大厅消失（跟随对局期显隐逻辑）。
【坑位】挂在大厅常驻 = 大厅里顶着一个准星录屏，穿帮。

**步骤 4.3 WBP_Hitmarker（射手侧）**
【操作】`+ Add` → Widget Blueprint → `WBP_Hitmarker`：Canvas 中心 4 条斜短线（45° 布局，白色）→ 默认 **Visibility=Collapsed**。
【逻辑】绑定 P2 的 OnFireResult：`shooterPid==自己 && bHit` → SetVisibility(Visible) → Delay 0.15s → Collapsed。
【验证】双 PIE：A 打中 B，A 屏幕闪四角线；打空不闪。
【坑位】shooterPid 判断用 `MatchSession` 的本地 PlayerId，别写死 1——双 PIE 两边都打才知道对错。

**步骤 4.4 WBP_HurtFlash（受击者侧，可选但建议做）**
【操作】`WBP_HurtFlash`：全屏 Image（纯红，Alpha 0）→ OnFireResult 里 `victimPid==自己 && bHit` → 淡入 0.15 → 淡出 0.3（用 Timeline 或简单 lerp）。
【作用】"被打要有感觉"——KPI 五段分解里 T4 对受击者同样成立。
【坑位】Image 别用默认纯白忘了改红；Alpha 起点 0，否则全程红屏。

**步骤 4.5 Debug HUD 血量行（掉血上镜载体）**
【操作】`WBP_DebugPanel` 对局页加一行**血量表**（各实体 PlayerId → hp），数据源 = P2 维护的实体血量缓存（21 号驱动，未命中不改值）。
【验证】A 打中 B：表里 B 的血量 100→75；打空不变。
【作用】"掉血全链路"的画面证据——总纲演示口径的落点，ep07 血条 UI 的数据源同一份。
【坑位】hp 是 21 号广播的全员值，别只在 victim 本地显——射手视角看到对方掉血才是"命中有后果"的完整体验。

## M5-F 地图几何烘焙（穿墙防线 · 编辑器期，2026-10-24 改版）

**步骤 6.1 给遮挡物挂标记组件**
【操作】NewMap 里选中参与挡弹的墙/箱子（可 Ctrl 多选）→ Details → Add Component 挂 `SightlineOccluder` 组件；形状特殊的在组件 Details 填自定义包围盒覆盖/偏移。
【验证】Outliner 里组件在位；**装饰性小物不挂**（服务器眼里它们不存在）。
【作用】标记 = 给任意 Actor 配"参与服务器碰撞"的角色（组合优于继承，下载地图的 Actor 类型不用改）；组件运行时零逻辑，只活在编辑器期。

**步骤 6.2 一键烘焙**
【操作】编辑器控制台（` 键）输入 `Srv.BakeOccluders`（或 Editor Utility 按钮）→ 扫描全部标记组件 → 枚举简单碰撞原语（盒/球带姿态）+ 读角色胶囊真身 → 生成 `server/assets/maps/NewMap.json`。
【验证】JSON 里 occluders 条数 = 挂组件数；entityHitbox 的 radius/halfHeight = 胶囊组件真实参数（不是默认 40/90）。
【作用】"图=代码一致"从人肉对齐升级为**机器对齐**——同一份文件双端生产消费。

**步骤 6.3 服务器加载验证**
【操作】重启服务器 → 启动行应出现几何合同加载行（盒子/原语数量）；进对局按验收第 9 条打箱子。
【坑位】①mesh 带旋转 OK——原语带姿态，服务器 OBB 局部系求交，不再"变胖"；②无简单碰撞的 mesh 退化 AABB 兜底（略胖，蓝图方案注明）；③**改了地图忘重烘 = 双端不一致**，验收第 9 条当场翻车；④JSON 缺失/非法 → 服务器启动即 fail-fast（装配错误不留活口）。
