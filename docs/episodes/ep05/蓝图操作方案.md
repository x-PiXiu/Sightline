## M5-A 输入资产（Content/Code/Input/）

**步骤 1.1 建 IA_Fire**
【操作】`+ Add` → Input → **Input Action** → 命名 `IA_Fire` → Value Type 保持 **Digital(bool)**，Trigger 默认 **Down** → Ctrl+S。
【作用】开火是开关量。**按住=全自动**（D5-14）：C++ 侧记 held 状态 + 100ms 节流循环（P7 前的 P1），松开停——输入系统自带 Repeat 周期不可靠且与节流双轨打架；点按=同一通路走一遍。
【坑位】别建成 Axis1D（按住每帧触发，节流白写）；也别用输入系统 Repeat 实现连发——节流必须单点管理。

**步骤 1.2 IMC_Default 加映射**
【操作】双击 `IMC_Default` → Mappings + → IA_Fire → 键位 **Left Mouse Button**。
【验证】IMC 列表出现 LMB → IA_Fire。
【坑位】ep03 的 IA_Look 若绑了鼠标移动，别覆盖——IMC 里是并列条目不是互斥。

**步骤 1.3 角色接线确认（零操作步）**
【说明】C++ 构造期自动加载 `/Game/Code/Input/IA_Fire` 进 FireAction（与 IA_Move 同款 ConstructorHelpers）——**资产建好即自动接线，BP Character 里无需手填**；资产未建时静默跳过（开火键无反应的第一排查点=IA_Fire 是否已建）。
【验证】建好 IA_Fire 后重编译/重开工程，PIE 按左键 → TryFire 触发。

## M5-C 角色开火动画（ABP 加槽 + 蒙太奇）

**步骤 3.1 ABP AnimGraph 终版接线（2026-10-25 定稿——合并 2.5/2.6/槽名改名，共四处改动）**
【现状（ep03 建成态）】`状态机 → LocoPose → AO_MM_Unarmed_Idle_Ready(Base=LocoPose·Pitch) → Slot「UpperBody」→ 输出`。
【目标链（v2 修正——姿势线单连接，分叉须走缓存姿势，用户实操抓）】`LocoPose → AO_Rifle_Idle_Hipfire.BasePose；Pitch → AO.Pitch（Yaw 留 0）；AO 输出 → Save Cached Pose「AimPose」；使用缓存姿势 AimPose → Slot「FullBodyAdditivePreAim」.Source；使用缓存姿势 AimPose → LBPB.BasePose；Slot 输出 → LBPB.BlendPoses[0]；LBPB(spine_03 含子骨) → 输出姿势`。（AO 输出直连两处不可行——UE 姿势脚单连接，分叉=缓存姿势，同 LocoPose 手法。）
【四处改动】①AO 资产换 Rifle_Hipfire（2.5）；②Slot Name：UpperBody → **FullBodyAdditivePreAim**（蒙太奇声明的槽名——改名才能接住 AM_MM_Rifle_Fire，此为能否播放的关键一步）；③插入 LayeredBlendPerBone（2.6）；④重连线如目标链。
【验证】PIE 三条：站立持枪戒备 / 跑动腿是跑上身持枪 / 开枪上身火动+腿不受干扰。没播=查 Slot Name 与蒙太奇声明逐字符一致（输出日志过滤 Animation 看跳过原因）。
【语义】槽名是全局注册表字符串，ABP 里必须有**同名 Slot 节点**才接得住蒙太奇（无节点=静默不播）；改名后 UpperBody 名不再使用（ep14 需要再挂回，无冲突）。

**步骤 3.2 开火蒙太奇——定稿：直接播原包（2026-10-25 用户实勘闭环）**
【结论】AM_MM_Rifle_Fire 声明插槽 = `DefaultGroup.FullBodyAdditivePreAim`，我们 ABP 中**存在同名 Slot**（用户双端确认）——**FireMontage 直接填原包，零包装零新建**，路线 A 成立。
【操作】BP_Character_Manny/Quinn → Class Defaults → Sightline|Fire → FireMontage = AM_MM_Rifle_Fire。
【注意（Additive 叠加观感）】该槽语义=叠加在 Base Pose 上的预瞄准层——开火动作叠加在跑/待机之上（近似 ep14 想要的"跑动开枪腿不停"），若叠加姿态异常再回包装路线；ABP 里我们自己的 DefaultGroup.UpperBody Slot 暂时空置（无害，ep14 复用）。
【验证】PIE 开枪：上身开火动作+枪声；BlendOut 异常再调包装。

**步骤 3.3 C++ 触发（等 P3）**
【操作】BP_Character_Manny → Class Defaults → 把 `AM_Code_Rifle_Fire` 填进 P3 暴露的 ExposeOnSpawn/Defaults 字段（如 `FireMontage`）。
【验证】PIE 开枪：角色上身抬枪、松开回 locomotion，跑动中开火不打断腿部。
【坑位】若上身槽播了但角色瞬回原姿势——蒙太奇混合出时间太短，包装蒙太奇 BlendOut 调 0.2s。

## M5-D 准星 + 命中反馈 UI（Content/Code/UI/）

**步骤 4.1 WBP_Crosshair（逐控件操作）**
【操作】
1. `+ Add` → User Interface → **Widget Blueprint** → 命名 `WBP_Crosshair` → 父类选 **UserWidget 裸基类** → 双击打开进 Designer；
2. 调色板（左上 Palette）→ Common → 把 **Image** 拖进画布（共拖 4 个）；
3. 逐个选中 → 细节面板 → Canvas Panel Slot 区：**锚点（Anchors）点九宫格正中心图案（居中锚点——四条线永远跟随屏幕中心，分辨率无关）**，按下表填 Position/Size：

| 线 | Position X | Position Y | Size X | Size Y |
|---|---|---|---|---|
| 上（竖） | -1 | -40 | 2 | 10 |
| 下（竖） | -1 | 30 | 2 | 10 |
| 左（横） | -40 | -1 | 10 | 2 |
| 右（横） | 30 | -1 | 10 | 2 |

4. 四条逐个：细节 → Appearance → Brush → **Color 取色器 R/G/B=1、Alpha=0.4**（白色 40% 透明）；
5. Compile + Save。
【成品】屏幕正中心四条 2×10/10×2 白色短线、中缝留空——纯色矩形拼十字，零贴图。
【作用】开火方向参照物——玩家瞄哪，射线从相机沿视线走。
【坑位】别做成大十字准星贴图——先 4 条 Image 凑，ep14 手感打磨期再换图。

**步骤 4.2 挂进对局 HUD**
【操作】对局期 UI 挂载点（与 WBP_DebugPanel 同处，PIE 对局期 AddToViewport 的那个位置）加一行：Create Widget WBP_Crosshair → Add to Viewport（ZOrder 低于 DebugPanel）。
【验证】进对局见准星，回大厅消失（跟随对局期显隐逻辑）。
【坑位】挂在大厅常驻 = 大厅里顶着一个准星录屏，穿帮。

**步骤 4.3 WBP_Hitmarker（射手侧 · 走对象池）**
【操作】`+ Add` → Widget Blueprint → `WBP_Hitmarker`：Canvas 中心 4 条斜短线（X 形布局，白色）→ 默认 **Visibility=Collapsed**。四条逐个：拖 Image → 细节 → Canvas Panel Slot → 锚点居中 → Render Transform（变换）区 **Angle** 填旋转角、Translation 填偏移、Size 填尺寸：

| 线 | Angle | Translation X | Translation Y | Size X | Size Y |
|---|---|---|---|---|---|
| 左上→右下（＼） | 45 | -24 | -24 | 2 | 14 |
| 右上→左下（／） | -45 | 24 | -24 | 2 | 14 |
| 左上→右下（＼·远） | 45 | 24 | 24 | 2 | 14 |
| 右上→左下（／·远） | -45 | -24 | 24 | 2 | 14 |

（四条相对中心对角摆放成 X 形；数值非精确美术值，PIE 看着调对称即可）
【逻辑】绑定 P2 的 OnFireResult：`shooterPid==自己 && bHit` → **对象池 Acquire（P7）** → AddToViewport → 播放 → 0.15s 后 **Release（隐藏归池，不销毁）**。
【验证】双 PIE：A 打中 B，A 屏幕闪四角线；连打 10 发/秒无卡顿（销毁 churn 被池吸收）；打空不闪。
【坑位】①shooterPid 判断用 `MatchSession` 的本地 PlayerId，别写死 1——双 PIE 两边都打才知道对错；②Acquire 必配 Release（RAII guard），归还即重置（隐藏+清计时器）；③600 RPM 并发峰值 2~3 个 → 预热 4、上限 8，超限强回收最老。

**步骤 4.4 WBP_HurtFlash（受击者侧，可选但建议做）**
【操作】`WBP_HurtFlash`：全屏 Image（纯红，Alpha 0）→ OnFireResult 里 `victimPid==自己 && bHit` → 淡入 0.15 → 淡出 0.3（用 Timeline 或简单 lerp）。
【作用】"被打要有感觉"——KPI 五段分解里 T4 对受击者同样成立。
【坑位】Image 别用默认纯白忘了改红；Alpha 起点 0，否则全程红屏；**常驻单实例重播**（受击打断重播）——比池更省，池留给并发场景（Hitmarker）。

**步骤 4.5 音效接线（最低配四音 · D5-10v2 · 资产 2026-10-27 实勘定案）**
【操作】四个音全部软引用（`TSoftObjectPtr<USoundBase>`，**填在 BP_Character_Manny/Quinn 的 Class Defaults → Sightline|Fire 分类**——C++ 侧无默认路径）：①射手枪声——**`MSS_Weapons_Rifle_Fire`**（Lyra 正版枪声 MetaSound，`Audio/Sounds/Weapons/Rifle/` 实勘在库，Migrate 时连同 `ATT_Rifle` 衰减预设一起）；②命中音——暂用 `Weapons_Rifle_Mech_01`（机械音替代，ep14 换专用命中音）；③他人枪声——同①（2D 播放）；④受击音——同②。①本地节流过即播（`PlaySoundAtLocation`，与播动画同点，表现层预测零延迟）；②③④挂 P2 的 OnFireResult 三分流（命中=shooterPid 自己且 bHit；他人枪声=shooterPid 非自己；受击=victimPid 自己），收 21 号即播。
【验证】双 PIE：A 开枪 A 立即有声；B（受击者）听到枪声+命中音；第三人视角听到枪声但无命中音。
【坑位】①`PlaySoundAtLocation` fire-and-forget=**每发 transient AudioComponent**（引擎内部分配，10 次/秒量级可接受——ep14 音效体系期换常驻 AudioComponent 复用，2026-10-27 资源流审计登记）；②MetaSound 迁移依赖=ATT_Rifle 衰减预设，Migrate 对话框里**必须带上**（否则 2D 播没问题、3D 衰减报错）；③音量先默认，混音/衰减调优=ep14 体系期；④软引用加载失败=静默无声（不崩），兜底=射手枪声剪映后期贴——他人枪声/命中音**没法后期贴**（事件在服务器侧，对帧不可行）。

**步骤 4.6 Debug HUD 血量行（掉血上镜载体）**
【操作】`WBP_DebugPanel` 对局页加一行**血量表**（各实体 PlayerId → hp），数据源 = P2 维护的实体血量缓存（21 号驱动，未命中不改值）。
【验证】A 打中 B：表里 B 的血量 100→75；打空不变。
【作用】"掉血全链路"的画面证据——总纲演示口径的落点，ep07 血条 UI 的数据源同一份。
【坑位】hp 是 21 号广播的全员值，别只在 victim 本地显——射手视角看到对方掉血才是"命中有后果"的完整体验。

## M5-F 地图几何烘焙（穿墙防线 · 编辑器期，2026-10-24 改版）

**步骤 6.1 给遮挡物挂标记组件**
【操作】NewMap 里选中参与挡弹的墙/箱子（可 Ctrl 多选）→ Details → Add Component 挂 `SightlineOccluder` 组件；形状特殊的在组件 Details 填自定义包围盒覆盖/偏移。
【验证】Outliner 里组件在位；**装饰性小物不挂**（服务器眼里它们不存在）。
【作用】标记 = 给任意 Actor 配"参与服务器碰撞"的角色（组合优于继承，下载地图的 Actor 类型不用改）；组件运行时零逻辑，只活在编辑器期。

**步骤 6.2 一键烘焙**
【操作】编辑器控制台（` 键）输入 `Srv.BakeOccluders`（或 Editor Utility 按钮）→ 扫描全部标记组件 → 枚举简单碰撞原语（盒/球带姿态）+ 读角色胶囊真身 → 生成 `server/assets/maps/NewMap.json`。
【验证】JSON 里 occluders 条数 = 挂组件数；entityHitbox 的 radius/halfHeight = 胶囊组件真实参数（不是默认 40/90；**以 BP_Character_Manny 的 CapsuleComponent 为准**）。
【作用】"图=代码一致"从人肉对齐升级为**机器对齐**——同一份文件双端生产消费。

**步骤 6.3 服务器加载验证**
【操作】重启服务器 → 启动行应出现几何合同加载行（盒子/原语数量）；进对局按验收第 9 条打箱子。
【坑位】①mesh 带旋转 OK——原语带姿态，服务器 OBB 局部系求交，不再"变胖"；②无简单碰撞的 mesh 退化 AABB 兜底（略胖，蓝图方案注明）；③**改了地图忘重烘 = 双端不一致**，验收第 9 条当场翻车；④JSON 缺失/非法 → 服务器启动即 fail-fast（装配错误不留活口）。
