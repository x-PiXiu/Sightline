## 设计决策记录

1. **四色语义与既有定稿同套**：黄=客户端手感侧 / 蓝=服务器判定侧 / 绿=无感通过 / 红=和解动作·非法路径 / 红虚=异常兑底 / 米白底红边=结论横幅——跨图一致，观众学一次用四次。
2. **服务器"唯一出场"原则**：t1 里服务器只有一个蓝框（权威框），t3 是它的正面镜头但被压成上镜版（三分支收成一句话，全图版指路脚注）。variant/Reactor 两节从口播整删，net_reactor/protocol_v4 降级 B-roll/纯仓库资产。
3. **旅程图替代状态机图上镜**：v2.0 分镜的主视觉是 C6 账本卡（焦点帧接力）；t1 是它的流程图等价物（讲结构），C6 保留做特写（讲案例）——图管结构、卡管特写，两层不冲突。
